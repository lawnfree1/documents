Project Brief

케이웨이컴퍼니 ERP 구축 기획 문서

MD · Sales · CS · 유저/권한 · 인프라까지 아우르는 사내 ERP의 1차 버전 범위를 정의합니다. 실사용 팀의 업무 흐름에 맞춘 데이터 모델과 화면/기능을 제안하며, 이후 ERD, API 스펙, 와이어프레임으로 확장 가능합니다.

버전: v0.1 Draft 작성: PM/DEV 문서 유형: 기획안

1. 매입처 관리 (MD)

관계: 매입처 1 → 품목 N
구조
