📌 통역사 파견/관리 시스템 – 기능 명세서 (Feature Specification v0.9)

1. 시스템 개요

본 프로젝트는 통역사 파견 및 업무 관리를 위해 관리자 ERP와 통역사 모바일 앱을 구축하여, 의뢰 등록 → 실시간 푸시 → 선착 수락 배정 → 서비스 시작/완료 기록 → 일정/현황 관리까지 전 과정을 시스템화하는 것을 목표로 합니다.

구성 요소
- 통역사 모바일 앱 (iOS/Android, 내부 배포용)
- 관리자 웹 ERP
- 백엔드 API 및 푸시 서버
- 실시간 상태 반영(WebSocket/Socket.IO)

2. 사용자 유형

1) 관리자(Admin)

  • 의뢰 등록/수정/삭제
  • 통역사 배정 현황 모니터링
  • 진행 상태(배정/시작/완료) 실시간 조회
  • 통역사·의뢰 일정 및 이력 관리

2) 통역사(User)

  • 의뢰 목록 및 상세 확인
  • 푸시 알림 수신
  • 즉시 수락 → 자동 배정 확정
  • 서비스 시작/완료 기록
  • 개인 일정 확인

3. 전체 흐름(Workflow)

  1. 국제 고객은 기존 플랫폼에서 예약·결제 완료
  2. 관리자 ERP에서 신규 의뢰 등록
  3. 모든 통역사 앱으로 푸시 알림 발송
  4. 통역사가 ‘즉시 수락’ → 서버 원자적 선착 배정
  5. 배정된 통역사에게 배정 확정 푸시 발송
  6. 현장 도착 후 서비스 시작
  7. 업무 종료 후 서비스 완료
  8. 관리자 ERP에서 실시간 상태 및 일정 확인

4. 기능 상세 명세 (Platform 별)

📱 4-1. 통역사 모바일 앱

1) 로그인 및 권한
  • 이메일/전화번호 기반 로그인
  • JWT 인증
  • 상태(휴무/활성) 설정 가능
2) 메인 화면
  • 신규 의뢰 리스트
  • 배정된 일정 캘린더
  • 진행 중 서비스 표시
3) 신규 의뢰 기능
  • FCM/APNs를 통한 신규 의뢰 푸시 수신
  • 의뢰 ID, 시간/장소, 요청사항 확인
  • 즉시 수락 → 원자적 선착 배정
4) 서비스 진행 기록
  • 서비스 시작(현장 도착 후)
  • 서비스 완료(종료 기록)
5) 일정/이력 확인
  • 월/주/일 캘린더
  • 상태별 필터링

💻 4-2. 관리자 웹(ERP)

1) 로그인/권한
  • 관리자 로그인
  • RBAC 권한 구조
  • 감사 로그 기록
2) 의뢰 관리
  • 의뢰 등록/수정
  • 리스트·상세 조회
  • 상태 이력 확인
3) 배정 관리
  • 통역사 전체 푸시 발송
  • 선착 배정 원자성 보장
  • 실시간 배정 현황 모니터링
4) 대시보드
  • 오늘 의뢰 수/배정률
  • 진행 상태 통계
  • 통역사별 실적
5) 일정 및 이력 관리
  • 통역사별 일정 캘린더
  • 의뢰 상태 히스토리

🔔 4-3. 알림/실시간

  • 푸시 알림(신규 의뢰/배정 확정)
  • 실시간 진행 상태 업데이트(WebSocket)

🗄 4-4. 백엔드/DB

  • NestJS 기반 REST API
  • JWT 인증 + RBAC
  • MySQL DB 테이블 설계
  • S3 파일 저장(선택)

5. 기술 스택

  • 모바일 앱: Flutter 또는 React Native
  • 관리자 웹: React
  • 백엔드: NestJS + MySQL
  • 인프라: AWS 서울 리전
  • 푸시: FCM / APNs
  • CI/CD: GitHub Actions
