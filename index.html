외주 개발 제안서

업체별 영업정보 및 변경이력 통합관리 시스템 구축

기간: 2026-01-05 ~ 2026-02-13 · 견적(예상): 700만원 · 플랫폼: Web

01. 프로젝트 이해

본 프로젝트는 기업의 영업 관리 과정에서 발생하는 업체별 영업정보, 변경이력, 연락처, 보고서를 한 곳에서 통합 관리할 수 있는 웹 기반 시스템을 구축하는 것을 목표로 합니다.
클라이언트가 정리한 요구사항을 기반으로, 실무에서 바로 활용 가능한 형태의 데이터 중심 효율화 시스템으로 설계하여 3개월 이내 개발을 완료하는 과정입니다.

02. 프로젝트 목적

  • 업체별 영업 정보 체계화 → 검색·조회·필터링을 통한 빠른 정보 접근
  • 담당자 연락처 및 변경이력 통합 관리 → 히스토리 기반 의사결정 지원
  • 기업 유형·에너지 등급 기반의 영업 타겟 발굴 기능 제공
  • 보고서 자동 생성 및 엑셀 다운로드로 업무 효율 극대화
  • 관리자 승인/권한 체계 도입으로 보안성과 관리 효율 확보

03. 개발 범위 설계

3-1. 기본 데이터 구조

Company 시트 업체명, 소재지, 기업 유형, 에너지 등급, 메모
Contact 시트 담당자명, 연락처, 이메일, 업체 ID 연동
보고서 시트 필터(기업 유형, 에너지 등급) 기반 업체 목록 생성, 엑셀 다운로드
관리자 기능 회원가입 승인, 변경이력 자동 저장 및 조회

3-2. 필요 기능 상세

  • 회원가입/로그인 – 관리자 승인 후 로그인 가능
  • 업체 정보 CRUD – 기업 유형, 등급, 메모, 상세 정보
  • 담당자 정보 CRUD – 업체별 담당자 다중 등록
  • 검색/필터 기능 – 기업 유형, 에너지 등급 기준 정밀 검색
  • 보고서 자동 생성 – 엑셀 다운로드(기업 유형/등급 기반)
  • 변경이력 기록 시스템 – DB Trigger 또는 Application 레이어에서 자동 기록
  • 관리자 페이지 – 회원 승인/계정 관리/변경이력 조회

04. 기술 스택 및 시스템 아키텍처

클라이언트가 요청한 JavaScript 기반 환경을 중심으로 개발합니다.

  • Frontend: HTML5, CSS3, JavaScript
  • Backend: Node.js (Express 또는 NestJS)
  • DB: MySQL · SQL 기반 정규화된 구조 설계
  • API 구조: RESTful API
  • 보고서: 엑셀 동적 생성 라이브러리 활용
  • 인증: JWT 기반 로그인 · 승인 기능

05. 개발 일정(예상)

총 약 3개월 일정으로, 실제 시작 시점에 맞춰 세부 WBS를 제공합니다.

1단계 (1~4주)
  • 요구사항 확정 및 ERD 구축
  • 회원가입/로그인/관리자 승인 기능
  • 기본 레이아웃 및 관리자 UI 디자인
2단계 (5~8주)
  • 업체 정보 CRUD 개발
  • 담당자 정보 CRUD 개발
  • 검색 및 필터 기능 구현
  • 변경이력 저장 구조 완성
3단계 (9~12주)
  • 보고서 자동 생성(XLSX)
  • 관리자용 변경이력 조회 페이지
  • 시스템 통합 테스트 및 QA
  • 배포 및 사용자 교육 문서 제공
본 제안서는 클라이언트가 제공한 요구사항을 기반으로 개발팀에서 재구성한 제안안입니다.
실제 미팅 후 세부 스펙과 WBS를 다시 제공해 드립니다.
